---
description: Customize an existing film style or create a new style from scratch
---

1. Read `MY-STYLES.md` to follow the 5-step style creation protocol.
2. Ask the user whether they want to modify an existing style in `styles/` or start from a blank canvas.
3. Gather visual preferences (color palette, typography, motion rhythm, camera grammar, 2D vs 3D).
4. Generate a `STYLE.md` and `demo.html` inside `my-styles/<new-style-name>/`.
5. Render a preview comparison frame with `python tools/preview_frame.py` and iterate until the user approves.
